Flow2API Captcha Worker

Ekstensi lokal untuk menghasilkan token reCAPTCHA Enterprise otomatis dari sesi Google Flow.

Status: Memeriksa koneksi...
Alamat WebSocket Flow2API lokal (default Bang Story: ws://127.0.0.1:8765/captcha_ws).
Masukkan API Key yang ada di menu Pengaturan Sistem Flow2API (default: 1234567) atau Kunci Ekstensi.
⚠️ PERHATIAN: Jika hanya menggunakan 1 akun, biarkan KOSONG (jangan diisi nomor port 8765!). Hanya diisi jika Anda mengonfigurasi multi-akun di Token Management.
Label pengenal browser ini di log server Flow2API.
